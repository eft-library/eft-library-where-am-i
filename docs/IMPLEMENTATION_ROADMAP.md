# 클라이언트 구현 단계표

기준일: 2026-10-19. 단계는 작업 묶음이며 대화 횟수나 정확한 소요 시간을 뜻하지 않는다. 발견한 결함에 따라 추가 작업이 생길 수 있다.

| 단계 | 작업 | 상태 |
| --- | --- | --- |
| 1~3 | 로그 분석·파싱·증분 감시 | 구현 |
| 4 | 레이드·타이머 전송 | 클라이언트 구현 |
| 5~6 | 상태 화면·활동 이력·스크린샷 전송 안정화 | 구현 |
| 7 | 지정 경로 최초 수집·보고 | 구현 |
| 8 | 버전 확인·다운로드 안내 | 클라이언트 구현 |
| 9 | 로그 선택·새 실행 폴더 전환 안정화 | 구현 |
| 10 | 맵 별칭 API 계약·로컬 캐시 준비 | 클라이언트 구현 |
| 11 | 통합 검사·남은 UI와 오류 처리 정리·Windows 검증 목록 | 완료, Windows 실사용 별도 |
| 12 | Release 패키징·사용 및 검증 문서 정리 | 로컬 패키지 생성 완료 |

계획한 클라이언트 12단계는 로컬 구현·검사·패키지 준비까지 완료했다. 맵 별칭은 내장 매핑·정상 캐시를 대체값으로 사용하는 클라이언트를 준비했다. Release는 로컬 산출물 준비이며 공개 배포를 뜻하지 않는다. 사용자 확정에 따라 앱 내 지도·수동 맵 선택은 기존 UI를 사용하고, 앱 내 실시간 타이머·이력 영구 저장 및 내보내기·독립 설정/전체 이력 페이지·자동 업데이트 설치는 추가하지 않는다.

백엔드 타이머 저장·전달, 웹 BTR 반영, 버전·맵 별칭 API는 [별도 요구사항](BACKEND_API_REQUIREMENTS.md)으로 관리한다. 실제 Windows 게임 플레이, 서버·웹 통합, UI·DPI 검증은 별도로 확인한다. 클라이언트 단계 완료만으로 운영 연동 완료를 선언하지 않는다.

## 최종 로컬 결과

C# 373개 검사와 Python 3개 테스트를 통과했고 Release Windows x64 self-contained 단일 실행 파일을 publish했다. 패키지는 `artifacts/where-am-i-4.0.0-win-x64.zip`, 해시와 manifest도 같은 폴더에 있다. [패키징 방법](RELEASE_PACKAGING.md)과 [Windows·운영 연동 검증표](WINDOWS_VALIDATION.md)를 따른다. 이번 배포 버전은 4.0.0(실행 표시 4.0.0.0)으로 확정했다.
