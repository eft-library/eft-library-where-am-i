# Windows 및 운영 연동 검증표

2026-10-19 기준. macOS의 C# 검사·Windows 교차 빌드·패키지 검사는 완료할 수 있으나 아래 항목은 실제 Windows/게임/서버 환경에서 확인해야 한다. 체크되지 않은 항목은 통과를 의미하지 않는다. 운영 API 호출은 로컬 자동 검사에 포함하지 않는다.

## Windows 실행과 화면

- [ ] Windows x64에서 ZIP을 새 폴더에 풀고 별도 .NET 설치 없이 실행한다.
- [ ] 상단 앱 버전 버튼으로 별도 창을 열고, 표시된 실행 버전이 패키지 버전과 일치한다. 닫기·Esc 후 감시가 계속되며 재확인·다운로드 버튼이 정상 동작한다.
- [ ] 이메일 확인 성공·실패·통신 오류와 이메일 저장/해제를 확인한다.
- [ ] 100%·150%·200% DPI와 최소 창 크기에서 스크롤·줄바꿈·버튼·긴 경로를 확인한다.
- [ ] 키보드 Tab 이동·버튼 실행·오류 필터·빈 이력 표시, 카드 상단 폴더 선택 버튼과 버튼 텍스트 좌우 여백을 확인한다.
- [ ] 최소화 후 트레이에서 복원하고, 종료 후 프로세스가 남지 않는다.
- [ ] 최초 안내 전에 즉시 종료해도 뒤늦은 안내 창이 뜨지 않는다.

## 파일 감시와 게임

- [ ] 기본 경로 자동 탐색과 사용자 지정 경로의 다음 실행 복원을 확인한다.
- [ ] `C:\Battlestate Games\EFT\Logs`에서 새 실행 폴더가 생성되면 application 파일 생성 후 전환한다.
- [ ] 지정 경로가 없어지면 다른 설치 위치로 우회하지 않고 기다리며 복구 후 감지한다.
- [ ] 새 실행 전환 시 이전 맵·타이머가 지워지고 이전 로그 수정으로 되돌아가지 않는다.
- [ ] Customs·Woods·Shoreline에서 맵·레이드 시작을 확인한다. Woods GameTimer 확보를 우선 확인한다.
- [ ] 타이머가 없는 로그는 임의 잔여 시간을 만들지 않고 웹 수동 입력을 유지한다.
- [ ] 게임 스크린샷을 여러 장 촬영해 최신 좌표를 보내고 일반 캡처 파일은 무시한다.
- [ ] 감지 중지·재개·종료 중 요청 취소, 파일 잠금·잘림·회전·폴더 재생성을 확인한다.

## 백엔드·웹 — 별도 구현/배포 필요

- [ ] 레이드 API가 timer_observed_at·raid_ends_at·session_id를 수신·전달한다.
- [ ] 개인 WebSocket과 재접속 캐시에 타이머 기준이 유지된다.
- [ ] 웹에서 현재 잔여 시간을 계산하고 Woods BTR 예상 운행에 반영한다.
- [ ] 타이머 없는 맵 전환에서 이전 타이머가 남지 않는다.
- [ ] 경로 수집의 마스킹·종류별 저장·실패 후 다음 실행 재시도를 확인한다.
- [ ] 버전 API의 최신·선택/필수 업데이트·실패·공식 다운로드 링크를 확인한다.
- [ ] 별칭 API 변경 후 로그 재분석, 오프라인 재실행 시 캐시 복원을 확인한다.

## 배포 전 확인

- [ ] 패키지 SHA-256 및 manifest의 파일별 해시를 확인한다.
- [ ] 이 빌드 자체의 백신 검사·코드 서명 여부를 확인하고 실제 결과만 기록한다.
- [ ] 위 Windows/서버 검증 결과를 기록한 뒤 공개 배포 여부를 결정한다.

확인자 / 실행한 패키지 SHA-256 / Windows·게임 버전 / 서버 배포 버전 / 결과 / 발견 문제를 함께 기록한다. 과거 이미지나 백신 검사 결과는 이번 빌드 검증을 대체하지 않는다.
