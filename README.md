# 내 위치 찾기 V 3.0

## 타르코프 도서관 사이트의 내 위치 찾기와 연동하는 프로그램 입니다.

게임에서 생성되는 스크린샷과 로그를 사이트의 실시간 지도에 연동합니다.

스크린샷 파일명의 좌표와 EFT application/output 로그의 현재 맵·레이드 시작·타이머 기준을 전달합니다. 게임 파일은 수정하지 않습니다. 정확한 종료·실제 트랜짓 연결은 감지하지 않습니다.

현재 소스에는 상태 카드·최근 활동·오류 필터를 적용했습니다. 아래 화면 이미지는 개편 전 참고 이미지입니다. 타이머 서버 수신·웹 BTR 반영과 버전·별칭 API는 별도 구현이 필요합니다.

## 사용법

압축을 푼 뒤, where-am-i.exe 파일을 실행하세요

처음에 화면을 진입하시면, 이메일을 입력하는 창이 나옵니다. 

![프로그램 실행 화면](docs/images/init.png)

EFT Library 계정 이메일을 입력한 뒤 **사용자 확인**을 누릅니다.

실패하면 실패했다는 알림이 나오고, 성공하면 화면이 이동합니다.

**실패**

![존재하지 않는 사용자 알림](docs/images/invalid_user.png)

등록되지 않은 이메일을 입력하면 **존재하지 않는 사용자** 알림이 표시됩니다.

**성공**

![스크린샷 감시 화면](docs/images/sucess.png)

사용자 확인에 성공하면 스크린샷 감시 화면으로 이동하고, 자동으로 찾은 감시 경로가 표시됩니다.

스크린샷 폴더가 자동으로 잡히지 않으면 **스크린샷 폴더 선택** 버튼으로 직접 추가할 수 있습니다.

![감시 폴더 직접 선택](docs/images/add_directory.png)

![감시 폴더 등록 완료](docs/images/add_success.png)

폴더가 정상 등록되면 감시 경로 목록에 새 경로가 추가됩니다.

성공시 자동으로 동작하기에 그냥 방치하시면 됩니다.

로그 폴더도 자동으로 탐색합니다. 직접 지정할 때는 `C:\Battlestate Games\EFT\Logs`처럼 설치 위치의 상위 Logs를 선택하세요. 사용자 지정 경로가 있으면 해당 범위만 감시합니다. 새 실행 폴더에 application 로그가 생기면 자동 전환하며 과거 파일 수정으로 되돌아가지 않습니다.

클라이언트는 감지한 맵·레이드 시작과 확보한 타이머 기준을 전송합니다. 타이머가 없으면 임의 값을 만들지 않습니다. 서버·웹 구현 및 검증 후 웹 BTR 자동화에 사용할 수 있습니다.

상단의 **감지 중지/감지 시작** 버튼으로 스크린샷과 로그 감시를 함께 제어할 수
있습니다. 설정은 다음 실행에도 유지됩니다.

이제 사이트의 내 위치 찾기 페이지로 가시면 바로 동작합니다.
